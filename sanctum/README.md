# Sanctum

onclimb-industries のローカルメモ Web アプリ（Obsidian 風）。
リポジトリ内の Markdown ファイルをブラウザから閲覧・編集・検索できる。
クライアント貸与 PC などメモアプリを入れられない環境でも、
`git clone` + Rust ツールチェインだけで動くことを目的にしている。

[topcoat](https://github.com/tokio-rs/topcoat)（tokio 製フルスタックフレームワーク）を使用。
外部 CLI やアセットビルドは不要で、`cargo run` だけで起動する。

## 起動

```sh
cd sanctum
cargo run
# → http://127.0.0.1:14141
```

既定ポートは **14141**（3000/5173/8080 等の定番開発ポート・macOS の AirPlay(5000)・
ephemeral 範囲(49152〜) と被らない番号）。

初回は `rust-toolchain.toml` により rustc 1.95 が自動インストールされる
（topcoat 0.4 の要求。グローバルの default toolchain は変更しない）。

### 常駐させる（macOS・任意）

ログイン時の自動起動が欲しくなったら launchd 登録スクリプトを使う（使わなくてもよい。
その場合は必要なときに `cargo run --release` で起動する）。

```sh
./scripts/install-launchd.sh            # release ビルド + ログイン時自動起動（ポート 14141）
# → http://127.0.0.1:14141 をブックマークしておく
./scripts/install-launchd.sh uninstall  # 解除
```

バイナリは `~/.local/bin/sanctum` にコピーして起動する
（`~/Documents` 配下のバイナリを launchd から直接起動すると macOS の保護フォルダ機構で
dyld がハングするため）。ログは `~/Library/Logs/sanctum.log`。
コードを更新したら install スクリプトを再実行すると差し替わる。

## 機能

### vim 風モーダル操作（閲覧 ⇄ 編集）

ノートは 1 ページで **NORMAL（装飾ビュー）/ INSERT（Markdown ソース編集）** を切り替える。
既定は NORMAL で装飾表示。`i` で INSERT に入り、`Esc` で保存して NORMAL に戻る
（右上のバッジが現在のモード）。切り替えボタンは無い。

| NORMAL のキー | 動作 |
|------|------|
| `i` / `a` | INSERT に入る（前回のカーソル位置） |
| `o` / `A` | 末尾に INSERT（`o` は改行して追記開始 — 素早いメモ追記用） |
| `j` / `k` | 下 / 上にスクロール |
| `Ctrl-d` / `Ctrl-u` | 半ページ下 / 上 |
| `gg` / `G` | 先頭 / 末尾へ |
| `/` | 検索ボックスへフォーカス |
| `Esc`（INSERT 中） | 保存して NORMAL へ |

### メモを取る

- **デイリーノート** — `/today` を開くと今日の `memo-data/daily/YYYY-MM-DD.md` の
  編集画面に直行（無ければ daily テンプレートを敷いて開く。保存は書き始めた時点）。
  サイドバーの「今日のメモ」からも 1 クリック。
- **テンプレート** — 組み込みの `daily` / `meeting`（MTG メモ: 参加者・決定事項・TODO）を
  ノート上部の選択 +「テンプレ挿入」で挿入。`{{date}}` `{{time}}` `{{datetime}}` は
  その場で展開される。「テンプレ編集」で選択中のテンプレートを開いて編集でき、
  組み込みは初回編集時に中身が展開された状態から始まり、保存すると
  `memo-data/templates/<name>.md` のカスタム版として組み込みより優先される。
  新しいテンプレートは「パスを開く」で `memo-data/templates/<名前>.md` を作れば
  選択肢に自動で加わる。
- **自動保存** — 編集を止めて 0.7 秒後に自動保存（⌘S で即時保存、Esc でも保存）。
- **競合検知** — Claude Code などが同じファイルを書き換えていたら上書き前に警告し、
  「読み込み直す／自分の内容で上書き」を選べる。編集中も外部変更を監視。
- **画像貼り付け** — エディタに ⌘V でスクショ等を貼ると、ノートと同じ階層の
  `attachments/` に保存して `![](attachments/...)` を自動挿入（png/jpg/gif/webp、20MB まで）。
- **新規ノート** — サイドバーの入力欄にパス（例: `ideas/foo`）。中間ディレクトリは自動作成。

### 読む・探す

- **ファイルツリー** — `memo-data/` を先頭に固定表示（削除不可）。他のフォルダは
  サイドバー下部の「ツリーにフォルダ追加」で明示的にパスを指定したときだけ記録・追加され、
  フォルダ名にホバーして出る × で外せる（`memo-data/config.json` に永続化）。
  `.` を追加すると vault 全体を表示。`projects/` など既定でインデックス外の
  フォルダを追加した場合は、その配下も ⌘K・検索・wikilink の対象に含まれる。
  ファイルを開いていないページ（`/`）には何も表示しない。
- **任意パスを開く** — サイドバー上部の「パスを開く・新規作成」にパスを入れると、
  ツリーに出ていないファイルも直接開いて編集できる（存在しなければ保存時に新規作成）。
- **クイックスイッチャー** — ⌘K でファジー検索パレット。Enter で開く、⌘Enter で編集を開く。
- **Markdown ビュー** — 表・タスクリスト・脚注・打ち消し線に加え、
  **Mermaid 図**（` ```mermaid `）と**コードのシンタックスハイライト**を表示。
- **目次** — 見出しが 3 つ以上あるノートは右上に目次を出してジャンプできる。
- **自動リロード** — 閲覧中のファイルが外部（AI 生成など）で更新されたら 3 秒以内に
  自動で再読み込み（スクロール位置は維持）。「Claude が書いているのを横で読む」ができる。
- **ノート間リンク** — Obsidian 互換の `[[wikilink]]`（stem 一致・パス最短優先で解決）。
  未作成ノートは赤破線で表示され、開くとその場で作成できる。バックリンクも自動表示。
- **検索** — ファイル名 + 本文の全文検索（大文字小文字無視、一致箇所ハイライト）。

### その他のショートカット

| キー | 動作 |
|------|------|
| ⌘K | クイックスイッチャー（ノート名で移動） |
| ⌘E | NORMAL ⇄ INSERT の切り替え（vim キーの代替） |
| ⌘S | 即時保存 |
| ⌘; | （INSERT 中）現在時刻を挿入（MTG 中の発言メモ用） |
| ⌘V | （INSERT 中）クリップボード画像を貼り付け |
| Tab | （INSERT 中）スペース 2 個 |

## 設定

### 起動時設定ファイル `sanctum/sanctum.json`（git 管理外・雛形は `sanctum.json.example`）

```json
{
  "memo_data": "memo-data"
}
```

- `memo_data`: メモ実データ置き場（vault 相対）。デイリーノート（`<memo_data>/daily`）・
  テンプレート（`<memo_data>/templates`）・ツリー設定（`<memo_data>/config.json`）・
  貼り付け画像はすべてこの配下に置かれ、ツリー先頭に固定表示される。
  vault 外に置きたい場合はシンボリックリンクを使う。
- ファイルが無ければ既定値（`memo-data`）で動く。

### 環境変数

| 変数 | 既定値 | 説明 |
|------|--------|------|
| `SANCTUM_VAULT` | カレントから遡って見つけた git ルート | パス解決の基準ディレクトリ（通常は設定不要） |
| `SANCTUM_EXCLUDE` | `projects` | インデックスから除外するディレクトリ名（カンマ区切り）。隠しディレクトリ・`node_modules`・`target` は常に除外 |
| `HOST` / `PORT` | `127.0.0.1` / `14141` | バインドアドレス |

`memo-data/` はデイリーノート・テンプレート・アプリ設定（`config.json`）・貼り付け画像の実データ置き場で、
機密を含みうるため `.gitignore` で git 管理外（リポジトリ直下の他のデータディレクトリと同じ扱い）。

## 設計メモ

### 常駐前提の低負荷設計

- **アイドル時の消費はゼロ**。バックグラウンドの監視スレッド・タイマーは持たず、
  vault のインデックス（ツリー・stem 索引・wikilink グラフ）はアクセス時に
  TTL 2 秒の遅延方式で再構築する（`src/index.rs`）。再構築でもファイル内容を
  読み直すのは mtime が変わったものだけ。自プロセスの保存は dirty フラグで即時反映。
- ブラウザ側のポーリング（閲覧の自動リロード 3 秒・編集中の外部変更監視 5 秒）は
  **タブが非表示の間は停止**する。ポーリング 1 回は mtime の stat のみ（実測 ~0.6ms）。
- tokio のワーカースレッドは 2 本に制限。launchd では `ProcessType: Background` +
  `LowPriorityIO` で他アプリの邪魔をしない。実測: 常駐 RSS 約 4MB、
  アイドル CPU 0.0%、ノート表示 ~2ms（522 ノートの実 vault・warm cache）。

### その他

- topcoat のランタイム（signal / shard）は現状 highly experimental のため使用せず、
  サーバーレンダリング + 素の JS（`assets/app.js`、`include_str!` で埋め込み）で構成。
  そのため `topcoat` CLI・アセットバンドルが不要で `cargo run` だけで完結する。
- Mermaid / highlight.js は CDN 非依存で `assets/vendor/` に同梱し、バイナリに埋め込んで
  `/vendor/*` から配信する（バージョン・SHA-256・更新手順は `assets/vendor/VENDOR.md`）。
- Markdown 変換は pulldown-cmark（`ENABLE_WIKILINKS`）。wikilink の解決は
  Obsidian 同様「ファイル名（stem）一致・パス最短優先」。
- 日付・時刻（デイリーノート名・`{{date}}`・⌘;）はすべてブラウザ側で解決する。
  サーバーはタイムゾーンを知らなくてよく、依存も増えない。
- 書き込みは `.md` と画像アップロードのみ・vault ルート外へのパスは拒否（トラバーサル対策）。
  削除機能は持たない（ファイル削除はエディタ/シェルで行う）。
- ローカル利用前提のため認証は無し。`HOST=0.0.0.0` での公開は想定していない。
